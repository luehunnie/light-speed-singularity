> 依据文档：《光速奇点》玩法设计 v1.0、《美术资源替换与 Godot 关卡编辑指南》v1.1、各机关规则文档

## 1. 设计总纲（玩家视角）

### 1.1 四条教学原则

1. **一关只教一个新概念**。教学关绝不叠加新概念；玩家每一关的"认知增量"只有一个。
2. **教学关强制单解，综合关有限开放**。教学关用地形把错误答案物理排除，玩家不需要猜；综合关才开始允许试错与规划。
3. **几何即提示**。墙放在"此路不通"的位置，水晶放在"应该在这里拐弯"的位置，让玩家读图就能得到暗示，不依赖文字。
4. **无惩罚试错**。失败没有代价（R 随时重置、水晶点亮后保持），教学关的移动次数要留出犯错空间。

### 1.2 难度与资源节奏

| 维度 | 教学 1 | 教学 2 | 综合 1 | 综合 2 |
|---|---|---|---|---|
| 新概念 | 运行流程 | 镜面放置与朝向 | RAY 形态 + 多水晶路径规划 | 形态切换 + 资源收紧 |
| 玩家决策点 | 0 | 2（位置 + 朝向） | 4（2 位置 + 2 朝向） | 6 + 资源压力 |
| 库存 | 无机关 | 2 镜面（需 1，富余 1） | 2 镜面（刚好） | 3 镜面（刚好） |
| 运行期移动次数 | 0 | 2（允许犯错 1-2 次） | 3（允许犯错 1 次） | 3（允许犯错 1 次） |
| 解法 | 唯一（无需解） | 唯一 | 唯一 | 唯一 |

节奏要点：**先教会"移动次数"和"配置锁定"的含义，再在综合关使用资源压力**。教学关库存略富余（建立安全感），综合关库存刚好（制造规划压力）。

### 1.3 基于当前实装的可行性边界

设计只使用**已实装**能力，全部四关可立即制作：

- ✅ 单格斜面镜（`/` 与 `\`，RAY 与 PARTICLE 均可反射，`single_cell_mirror.gd` 已声明双形态）
- ✅ 基础水晶（任何合法到达的光点亮，点亮后保持至 R）
- ✅ 主发射器八方向预置、PARTICLE 默认标准速度
- ✅ 五状态运行流程（SETUP → READY_TO_FIRE → PULSE_ACTIVE → MOVE_WINDOW → COMPLETED）、开始运行按钮、Space 连发、R 完整重置
- ✅ 机关栏库存、首次放置/移动/回收、运行期移动次数
- ✅ 光形态切换 Q（`allow_form_switch` 控制，M4-E4 实装）
- ✅ 目标条件系统支持按光形态过滤（`objective_condition_configuration.allows_light_form`）

**禁止在本批关卡使用的未实装机制**（设计红线）：

- ❌ 光屏障（代码未实装）
- ❌ 光粒速度监测器、颜色水晶、滤光片、分光器、光形式转换器
- ❌ 同时组 / 顺序组水晶
- ❌ 要求玩家在运行中调整发射器方向（八方向按键方案已冻结但**尚未实装**，所有发射器方向必须关卡预置）
- ❌ "必须分别用两种形态点亮两颗水晶"类目标——Q 切换仅限 SETUP，一次运行内形态锁定，R 会清空水晶，当前规则下此类目标无解（需等形态转换器）

## 3. 教学关 1：第一束光

### 3.1 设计意图

玩家的唯一任务是走完"观察 → 开始运行 → Space 发射 → 水晶点亮 → 通关"的最小闭环。零机关、零决策，把全部注意力留给 UI 状态流转和光的视觉反馈。这是经典的"第 0 关"设计：先让玩家感到"我能让它动起来"，再引入思考。

### 3.2 地图（10×7）

```text
##########
#........#
#........#
#E>.....c#
#........#
#........#
##########
```

### 3.3 配置

| 项 | 值 |
|---|---|
| 发射器 | cell (1,3)，方向 RIGHT，形态 PARTICLE，预置固定 |
| allow_form_switch | false |
| 水晶 | 1 颗基础水晶，cell (8,3)，必需 |
| 机关栏 | 空 |
| 运行期移动次数 | 0 |
| 可放置区域 | 无（或全部禁用，避免玩家困惑"为什么没东西可放"） |

### 3.4 预期解与教学提示

预期解：点击"开始运行" → READY_TO_FIRE → 按 Space → 光粒向右逐格移动 → 点亮水晶 → COMPLETED。

教学提示文案（关卡根节点"教学提示"字段）：

1. 进入关卡：「点击下方的"开始运行"按钮。」
2. 进入 READY_TO_FIRE：「按 Space 发射光粒。光粒点亮水晶即可通关。」
3. 通关结算时追加：「按 R 可以随时重置整关。」

### 3.5 设计理由与验证要点

- 故意不给任何机关：教学 1 如果引入机关，玩家会把"流程"和"解谜"混在一起学，两个都学不扎实。
- 水晶放在光路正末端且房间对称，玩家第一眼就能建立"发射器 → 水晶"的因果预期。
- 验证：初始 Space 无效、完成后冻结、R 回到 SETUP 并需重新点击开始运行（对应关卡检查清单 §26"运行"节）。

## 4. 教学关 2：转向

### 4.1 设计意图

一次教会三件事：① 从机关栏拿取与放置；② 镜面 `/` 与 `\` 朝向的区别（右键切换）；③ 开始运行后配置锁定、但布局仍可移动（扣次数）。

### 4.2 地图（11×9）

```text
###########
#.........#
#E>..m#...#
#.........#
#.........#
#....c....#
#.........#
#.........#
###########
```

### 4.3 配置

| 项 | 值 |
|---|---|
| 发射器 | cell (1,2)，方向 RIGHT，形态 PARTICLE，预置固定 |
| allow_form_switch | false |
| 水晶 | 1 颗基础水晶，cell (5,5)，必需 |
| 墙体 | cell (6,2)——封死直射路径，几何提示"必须拐弯" |
| 机关栏 | 单格镜面 ×2（只需 1 个，富余 1 个供试错） |
| 运行期移动次数 | 2 |
| 可放置区域 | 内部地面大部分标为合法，含 (5,2) 及若干干扰格 |

### 4.4 预期解

1. 从机关栏拿取镜面（默认朝向 `/`），放置在 (5,2)；
2. 发现 `/` 会把向右的光反射向上（`/` 反射公式 `(-y,-x)`：RIGHT → UP），光粒撞墙——**这是有意安排的失败教学**，让玩家亲眼看到朝向的影响；
3. 右键把镜面切换为 `\`（`/` ↔ `\` 仅 SETUP 可改，教配置锁定概念）；
4. 开始运行 → Space：`(1,2)→…→(5,2)` 遇 `\` 反射为 DOWN（`(y,x)`：RIGHT → DOWN）→ `(5,3)(5,4)(5,5)` 点亮水晶。

教学提示文案：

1. 「从下方机关栏按住镜面，拖到格子里。」
2. 「右键点击镜面可切换 / 和 \，两种朝向反射方向不同。」
3. 「放置完成后点击"开始运行"。开始运行后不能再改朝向。」
4. （可选，首次运行期移动时）「发射后仍可移动镜面，但会消耗移动次数。」

### 4.5 设计理由

- **单解强约束**：墙 (6,2) + 水晶 (5,5) 的几何关系把镜面唯一合法位置锁死在 (5,2)，朝向二选一也有唯一正确答案，教学关不产生开放困惑。
- **默认朝向 `/` 是故意的**：新拿取默认 `/`（机关规则文档已冻结），玩家第一次发射大概率失败一次，用一次低成本的直观失败学会"朝向很重要"，比文字提示深刻得多。
- **库存给 2 个**：第二个镜面允许玩家尝试"再放一个会不会更好"，顺便自然体验回收（拖回机关栏）。
- 验证：朝向切换仅限 SETUP、运行期移动扣次数、回收后库存一致（关卡检查清单 §26"机关栏"节全项）。

## 5. 综合关 1：反射长廊（光线章节代表关）

### 5.1 设计意图

玩家第一次接触 RAY：与光粒不同，RAY 发射后**瞬时显示完整路径（约 1 秒）**，"规划—发射—观察整条路径"的思考节奏与光粒不同。机制本身（镜面）已在教学 2 学会，迁移成本为零，新体验集中在形态差异与"一次发射串联两颗水晶"的路径规划。

### 5.2 地图（13×10）

```text
#############
#E>.......m##
#...........#
#...........#
#.........c.#
#...........#
#...........#
#...c.....m.#
#.........#.#
#############
```

### 5.3 配置

| 项 | 值 |
|---|---|
| 发射器 | cell (1,1)，方向 RIGHT，形态 RAY，预置固定 |
| allow_form_switch | false |
| 水晶 | A：cell (10,4)，必需；B：cell (4,7)，必需（均为基础水晶） |
| 墙体 | (11,1) 封死第一走廊尽头、(10,8) 封死第二走廊尽头（几何提示转弯点） |
| 机关栏 | 单格镜面 ×2（刚好） |
| 运行期移动次数 | 3 |
| 可放置区域 | 两条走廊沿线及转角区域标为合法，远离路径的区域不标（减少无效搜索） |

### 5.4 预期解（一笔画路径）

1. 镜面 `\` 放 (10,1)：RIGHT → DOWN；
2. 镜面 `/` 放 (10,7)：DOWN → LEFT（`(-y,-x)`：(0,1) → (-1,0)）；
3. 一次发射，路径 `→ 沿第 1 行 → 沿第 10 列（点亮水晶 A）→ 沿第 7 行向左 → 点亮水晶 B`。

关键机制教学：**水晶点亮后保持**——两颗水晶由同一条光路先后点亮，无需分两次发射。

教学提示文案：「本关是光线（RAY）：发射后立即显示完整光路。用两面镜子让一束光先后穿过两颗水晶。」

### 5.5 设计理由

- **作为光线章节代表关**：玩法设计 §11 要求每章至少一个代表核心玩法的正式关卡；RAY 的核心体验（瞬时完整路径）在本关是主角。
- **墙作提示**：(11,1) 和 (10,8) 两块墙放在走廊尽头，暗示"这里是拐点"，玩家读图即可定位镜面区域，但朝向仍需自己判断——综合关的适度开放。
- **移动次数 3**：允许运行期纠正一次错误（例如朝向放反后移动一面镜子），但不够反复乱试，开始产生规划压力。
- 验证：两颗水晶均必需、通关进入 COMPLETED、光路显示约 1 秒后消失但水晶保持。

## 6. 综合关 2：双形态（混合章节）

### 6.1 设计意图

混合章节首关。玩家第一次获得 Q 形态切换权限：本关两种形态都能通关，目的是让玩家**亲身体验 RAY 与 PARTICLE 的差异**（瞬时路径 vs 逐格移动），为后续真正区分形态的关卡打底。同时库存收紧为刚好、路径三拐，考察前三关全部能力的综合运用。

> 注意：本关**不**强制"两种形态各点亮一颗水晶"。Q 仅限 SETUP 切换、运行内形态锁定、R 清空水晶，当前规则下该目标无解（需形态转换器实装后再设计）。目标条件系统虽已支持按形态过滤（`allows_light_form`），本批关卡暂不使用。

### 6.2 地图（14×11）

```text

#E>...m.#....#
#............#
#.....c......#
#............#
#.m...m......#
#.....#......#
#.c..........#
#............#
##############
```

### 6.3 配置

| 项 | 值 |
|---|---|
| 发射器 | cell (1,2)，方向 RIGHT，初始形态 PARTICLE，预置固定 |
| allow_form_switch | **true**（本关核心体验） |
| 水晶 | 途经水晶：cell (6,4)，必需；终点水晶：cell (2,8)，必需（均为基础水晶） |
| 墙体 | (8,2) 封死第一走廊、(6,7) 封死第二走廊向下延伸 |
| 机关栏 | 单格镜面 ×3（刚好） |
| 运行期移动次数 | 3 |
| 可放置区域 | 路径沿线走廊标为合法，其余区域大部分不标 |

### 6.4 预期解（三拐 Z 字形）

1. 镜面 `\` 放 (6,2)：RIGHT → DOWN（途经水晶 (6,4) 点亮）；
2. 镜面 `/` 放 (6,6)：DOWN → LEFT；
3. 镜面 `/` 放 (2,6)：LEFT → DOWN（`(-y,-x)`：(-1,0) → (0,1)）；
4. 光向下点亮终点水晶 (2,8)，通关。

PARTICLE 与 RAY 两种形态走完全相同的路径均可通关。

教学提示文案：

1. 「本关可按 Q 在光线和光粒之间切换（仅布置阶段有效）。两种形态都能通关，试试它们的差别。」
2. 「三面镜子要用在刀刃上——库存刚好够。」

### 6.5 设计理由

- **形态切换是"体验"不是"门槛"**：两种形态都能过关，避免无解陷阱的同时完成混合章节的点题。
- **途经水晶强制路径**：水晶 (6,4) 把第一个拐弯锁死在第 6 列，排除"提前拐弯"的替代解，保持唯一解但思考量明显高于教学关。
- **库存刚好 + 移动次数 3**：综合关的资源压力组合——够完成任务，但不够随意试错。
- 验证：Q 切换仅限 SETUP、开始运行后形态锁定、R 恢复初始形态（形态切换提示 UI 正常）、移动次数扣除正确。

## 7. 落地与验收

### 7.1 制作流程（遵循关卡编辑指南 §22）

确定章节 → 复制关卡模板 → 保存到 `levels/campaign/` 对应章节目录 → 依次绘制 Terrain / Wall / LegalArea / Decoration → 放置发射器与水晶 → 配置机关栏与移动次数 → 运行 LevelValidator → 人工测试 → 记录解法。

文件命名建议（指南 §21）：`particle_level_01.tscn`（教学 1）、`particle_level_02.tscn`（教学 2）、`ray_level_01.tscn`（综合 1）、`mixed_level_01.tscn`（综合 2）。

### 7.2 每关必过检查（指南 §26 摘要）

- 地图：四层正确、无越界、无重复占用；
- 发射器：位置/方向/光形态正确，玩家不可移动；
- 水晶：条件、必需标记、点亮与 R 恢复、通关；
- 机关栏：种类数量、放置/移动/回收/重置；
- 通用：可完成、可重置、有预期解、无死局、无越权捷径、不修改核心脚本。

### 7.3 关卡记录（指南 §27，每关至少记录）

关卡名称、所属章节、主要机制、使用机关、发射器配置、关卡目标、玩家库存、运行期移动次数、预期解法、允许的替代解法（本批四关均为唯一解）、已知问题、所需美术、测试日期、测试人员。

## 8. 风险与后续扩展

| 风险 | 说明 | 应对 |
|---|---|---|
| 教学 1 过于简单 | 零决策关卡可能被核心玩家觉得"空" | 定位为流程关，控制在 30 秒内通关；不加任何额外内容 |
| 发射器方向键未实装 | 玩家无法自行调向，若后续实装可能改变解法空间 | 四关发射器方向均预置且几何上唯一解不受影响 |
| 速度机关（加速器/减速器）无目标依托 | 屏障与速度监测器未实装，速度档位当前无玩法意义 | 本批关卡不使用加速器/减速器；待屏障实装后在混合章节追加速度主题关 |
| 双形态强制目标不可设计 | Q 仅 SETUP、R 清空水晶 | 等光形式转换器实装后再做形态分流关卡 |

后续扩展方向（9 月 5 日后）：屏障 + 速度档位关（慢速不能穿屏障）、颜色水晶与滤光片关、同时组/顺序组限时关、利用运行期移动做"发射后补救"的动态关。
