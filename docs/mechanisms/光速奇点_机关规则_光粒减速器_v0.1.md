## 1. 机关概述

光粒减速器是玩家可放置的速度型机关，占据一个网格格，与光粒加速器形成配对。减速器有 8 个减速方向，光粒进入后若运动方向与减速方向匹配，则速度降低一档（快速→标准→慢速），不低于最低档；方向不匹配时光粒穿透无影响。

减速器对光线（RAY 形态）无交互——光线正常穿透，保持原方向继续传播。当前光粒系统尚未实装，减速器的核心规则为预定义 ⏳。

## 3. 交互规则

### 3.1 与光线交互 ⏳ ❌

减速器对光线无影响。光线进入减速器所在格后保持原方向继续传播。

| 响应类型 | 条件 | 传播行为 |
|---|---|---|
| 继续 | 光线形态（任何入射方向） | 保持入射方向继续传播，无速度变化 |

**逐格传播顺序**（玩法设计 §6）：

```
1. 光进入下一格
2. 记录该格（坐标、入射方向、是否有水晶）
3. 尝试激活该格水晶
4. 查询机关 → 减速器 → 继续（光线不受影响）
5. 从当前格沿原方向继续传播
```

> 减速器对光线的"穿透无影响"行为为临时规则，标记为「待成员确定」。若后续设计决定减速器对光线也有交互，本节将更新。

### 3.2 与光粒交互 ⏳

目标规则，待光粒系统实现后验证：

- **方向过滤**：光粒运动方向必须与减速器的减速方向一致，才触发减速；方向不匹配时光粒穿透无影响，保持原速度和原方向 ⏳待成员确定
- **速度变化**：匹配方向的光粒速度 -1 档：快速→标准、标准→慢速、慢速→保持慢速（已达下限，不变化）
- **叠加规则**：多个减速器在串联路径上可叠加效果（如快速→标准→慢速），受最低档（慢速）保护，不低于下限
- **一格一机关**：放置规则保证同一格最多放置一个减速器，不存在同格叠加
- **速度生效时机**：速度变化从离开减速器格后的下一传播步开始生效（遵循"从下一格生效"模式）
- **Tick 行为**：光粒经过减速器格的 Tick 计为一步传播，速度变化影响后续 Tick 间隔

### 3.3 与发射器的关系

本机关不直接影响发射器。发射器发出的光粒按 §3.2 规则与本机关交互。

### 3.4 玩家操作权限

| 操作 | SETUP | READY_TO_FIRE ⏳ | PULSE_ACTIVE | MOVE_WINDOW | COMPLETED |
|---|---|---|---|---|---|
| 从库存拿取 | ✅ | ✅ | ✅ | ✅ | ❌ |
| 首次放置 | ✅ | ✅ | ✅ | ✅ | ❌ |
| 跨格移动 | ✅ | ✅ | ✅（扣移动次数） | ✅（扣移动次数） | ❌ |
| 回收至库存 | ✅ | ✅ | ✅ | ✅ | ❌ |
| 切换内部配置（右键切换方向） | ✅ | ❌ | ❌ | ❌ | ❌ |
| 拖拽取消/回滚 | ✅ | ✅ | ✅ | ✅ | ❌ |

> 布局编辑（放置/移动/回收）在所有非 COMPLETED 状态下允许。
> 内部配置（减速方向）仅在 SETUP 状态下可编辑。
> 运行期跨格移动消耗移动次数；首次放置、回收和取消不消耗。

### 3.5 与其他机关的交叉规则

> 基础规则：所有机关和场上物体不可重叠放置。

| 场景 | 规则 |
|---|---|
| 减速器 + 镜面（斜面镜/平面镜） | 光粒先经过镜面反射，再经过减速器 → 反射方向由镜面决定，速度变化由减速器决定（方向匹配则减速） |
| 减速器 + 墙体 | 光粒先经过减速器（如方向匹配则减速），再被墙体阻挡 → 减速效果在墙体阻挡前已生效 |
| 减速器 + 水晶 | 光粒经过减速器减速后击中水晶 → 水晶正常激活，激活判定不受速度影响 |
| 减速器 + 减速器（串联） | 速度叠加：快速→标准→慢速，不低于最低档。每个减速器独立判定方向匹配 |
| 减速器 + 加速器（未来） | 减速 -1 与加速 +1 互相抵消，保持原速度 |

## 4. 边界条件

| # | 边界条件 | 行为 |
|---|---|---|
| 1 | 入射方向为零向量 `(0, 0)` | 非法方向，传播停止 |
| 2 | 入射方向分量绝对值大于 1（如 `(2, 0)`） | 非法方向，传播停止 |
| 3 | 光粒已处于最低速（慢速）经过减速器 | 保持慢速，不崩溃 |
| 4 | 光粒运动方向与减速器方向不匹配 | 穿透无影响，光粒保持原速度原方向继续传播 |
| 5 | 减速器在传播过程中被移除 | 传播停止，不崩溃 |
| 6 | 多个减速器串联叠加 | 由最低档（慢速）下限保护，不低于下限 |
| 7 | 运行期拖拽减速器期间光路经过原格 | 拖拽期间旧占用保留，原格仍视为有机关于占用（预览不写入占用记录） |
| 8 | 光粒尚未实现 | 光粒相关规则为预定义 ⏳，当前不阻塞光线功能 |
| 9 | 减速器放在地图边界格 | 合法放置，但光粒可能因下一格越界而停止传播 |
| 10 | 减速器与水晶不可放置在同一格 | 放置前校验会拒绝（一格最多一个机关） |

## 5. 配置锁定规则

| 规则项 | 说明 |
|---|---|
| 锁定内容 | 减速方向（右键切换不可用） |
| 锁定时机 | 目标行为：点击"开始运行"进入 READY_TO_FIRE 时锁定 ⏳；当前原型：非 SETUP 自动锁定 |
| 锁定后行为 | 右键减速器无响应，但可放置新减速器或移动已有减速器 |
| 解锁时机 | R 完整重置，回到 SETUP 状态 |
| 锁定期间可否移动 | ✅——锁定只关内部配置，布局编辑不受影响 |

## 6. 重置规则（R）

R 为完整关卡重置。对减速器的影响：

| 步骤 | 行为 |
|---|---|
| 1 | 若正在拖拽减速器，安全取消拖拽并恢复原位置 |
| 2 | 使当前脉冲失效 |
| 3 | 清除减速器的场上占用记录 |
| 4 | 移除减速器 |
| 5 | 库存数量恢复为关卡原始总量 |
| 6 | 运行状态回到 SETUP，锁定的方向恢复可编辑 |

> R 后重新从库存拿取的减速器默认为 →（RIGHT）方向，不保留 R 之前的方向。

## 7. 与其他系统的交互边界

> 核心原则：减速器只负责根据自身方向判定是否减速光粒，不越界修改其他系统的状态。

| 涉及系统 | 本机关与它的关系 |
|---|---|
| 光传播系统 | 光线形态：穿透无影响（CONTINUE）。光粒形态：查询减速器方向，方向匹配则速度 -1 档，传播继续 |
| 场上占用 | 减速器放置/移动/回收时登记或注销占用记录 |
| 库存 | 放置时消耗库存，回收时归还库存；新拿取默认 →（RIGHT）方向 |
| 运行状态 | 控制减速方向是否可编辑（SETUP 可切换，其余锁定）；不影响布局移动 |
| 视觉表现 | 减速方向切换对应外观变化；外观不反向决定减速行为 |

## 8. 减速方向与速度档位速查表

### 8.1 8 方向定义与切换顺序

右键切换按顺时针循环：→ → ↘ → ↓ → ↙ → ← → ↖ → ↑ → ↗ → →（循环）。

| # | 方向名称 | 向量 | 减速匹配的入射方向 | 右键后切换至 |
|---|---|---|---|---|
| 1 | → 右 | `(1, 0)` | → `(1, 0)` | ↘ |
| 2 | ↘ 右下 | `(1, 1)` | ↘ `(1, 1)` | ↓ |
| 3 | ↓ 下 | `(0, 1)` | ↓ `(0, 1)` | ↙ |
| 4 | ↙ 左下 | `(-1, 1)` | ↙ `(-1, 1)` | ← |
| 5 | ← 左 | `(-1, 0)` | ← `(-1, 0)` | ↖ |
| 6 | ↖ 左上 | `(-1, -1)` | ↖ `(-1, -1)` | ↑ |
| 7 | ↑ 上 | `(0, -1)` | ↑ `(0, -1)` | ↗ |
| 8 | ↗ 右上 | `(1, -1)` | ↗ `(1, -1)` | → |

### 8.2 速度档位变化表

| 入射速度 | 方向匹配时 | 方向不匹配时 |
|---|---|---|
| 快速 | → 标准（-1 档） | → 快速（不变） |
| 标准 | → 慢速（-1 档） | → 标准（不变） |
| 慢速 | → 慢速（已达下限） | → 慢速（不变） |

### 8.3 串联叠加示例

光粒路径上依次经过两个 → 方向的减速器：

| 步 | 位置 | 速度 | 说明 |
|---|---|---|---|
| 发射 | 发射器 | 快速 | 初始速度 |
| 经过 | 减速器 A | 标准 | 方向匹配，-1 档 |
| 经过 | 减速器 B | 慢速 | 方向匹配，再 -1 档 |
| 继续 | 后续路径 | 慢速 | 已达下限，不再变化 |

若第二个减速器的方向与光粒方向不匹配，则光粒保持标准速度继续传播。

### 8.4 加速器与减速器组合示例

光粒路径上先经过加速器（→ 方向），再经过减速器（→ 方向）：

| 步 | 位置 | 速度 | 说明 |
|---|---|---|---|
| 发射 | 发射器 | 标准 | 初始速度 |
| 经过 | 加速器 | 快速 | +1 档 |
| 经过 | 减速器 | 标准 | -1 档，回到原速度 |

两个机关串联时可互相抵消，光粒速度恢复为进入第一个机关前的值。

## 9. 测试用例

### 用例 1：速度档位变化

| # | 入射速度 | 方向匹配？ | 预期结果 |
|---|---|---|---|
| 1.1 | 快速 | ✅ 匹配 | 速度变为标准 |
| 1.2 | 标准 | ✅ 匹配 | 速度变为慢速 |
| 1.3 | 慢速 | ✅ 匹配 | 保持慢速（下限保护） |

**验证方式**：构造不同速度的光粒经过减速器，逐条比对速度变化结果。

### 用例 2：方向过滤

| # | 减速器方向 | 光粒方向 | 方向匹配？ | 预期结果 |
|---|---|---|---|---|
| 2.1 | → `(1, 0)` | → `(1, 0)` | ✅ | 减速 -1 档 |
| 2.2 | → `(1, 0)` | ↓ `(0, 1)` | ❌ | 穿透，速度不变 |
| 2.3 | → `(1, 0)` | ↗ `(1, -1)` | ❌ | 穿透，速度不变 |
| 2.4 | ↗ `(1, -1)` | ↗ `(1, -1)` | ✅ | 减速 -1 档 |
| 2.5 | ↙ `(-1, 1)` | ← `(-1, 0)` | ❌ | 穿透，速度不变 |

**验证方式**：对每个减速器方向，分别验证 8 种光粒入射方向中只有匹配方向触发减速。

### 用例 3：方向切换

| # | 操作 | 前置条件 | 预期 |
|---|---|---|---|

| 3.2 | 右键 | 当前 ↘ | 方向变为 ↓ |
| 3.3 | 连续右键 ×8 | 当前 → | 循环一圈后回到 → |
| 3.4 | 连续右键 ×8 | 当前 ↑ | 循环一圈后回到 ↑ |

### 用例 4：配置锁定

| # | 操作 | 游戏状态 | 预期 |
|---|---|---|---|
| 4.1 | 右键减速器 | SETUP | 方向切换 ✅ |
| 4.2 | 右键减速器 | PULSE_ACTIVE | 无响应 ❌ |
| 4.3 | 右键减速器 | MOVE_WINDOW | 无响应 ❌ |

### 用例 5：R 重置行为

| # | 前置条件 | 操作 | 预期 |
|---|---|---|---|
| 5.1 | 放置了一个 ↗ 方向减速器 | 按 R | 减速器消失，库存恢复，无残留占用 |
| 5.2 | R 之后 | 从库存拿取新减速器 | 默认 → 方向 |
| 5.3 | 拖拽中途 | 按 R | 拖拽安全取消，减速器恢复原位置再被收回 |

### 用例 6：串联叠加

| # | 布局 | 光粒初始速度 | 减速器 A 方向 | 减速器 B 方向 | 光粒方向 | 预期 |
|---|---|---|---|---|---|---|
| 6.1 | 两个 → 方向减速器串联 | 快速 | → | → | → | 快速→标准→慢速 |
| 6.2 | 两个 → 方向减速器串联 | 标准 | → | → | → | 标准→慢速→慢速（下限） |
| 6.3 | A=→, B=↑ 串联 | 快速 | → | ↑ | → | 快速→标准（A 匹配，B 不匹配） |
| 6.4 | A=→, B=↑ 串联 | 快速 | → | ↑ | ↑ | 快速→快速（A 不匹配，B 匹配→标准） |

**验证方式**：构造不同路径组合，验证速度叠加行为和方向过滤的正确性。

### 用例 7：加速器与减速器组合

| # | 布局 | 光粒初始速度 | A（加速器）方向 | B（减速器）方向 | 光粒方向 | 预期 |
|---|---|---|---|---|---|---|
| 7.1 | 加速器 → 减速器 串联 | 标准 | → | → | → | 标准→快速→标准（抵消） |
| 7.2 | 加速器 → 减速器 串联 | 慢速 | → | → | → | 慢速→标准→慢速（抵消） |
| 7.3 | 减速器 → 加速器 串联 | 快速 | → | → | → | 快速→标准→快速（抵消） |
| 7.4 | 加速器 → 减速器 串联 | 标准 | → | ↑ | → | 标准→快速→快速（加速匹配，减速不匹配） |

**验证方式**：验证加速 +1 与减速 -1 互相抵消，以及方向不匹配时各自独立生效。
