## 6. 重置规则（R）

R 为完整关卡重置。对本机关的影响：

| 步骤 | 行为 |
|---|---|
| 1 | 若正在拖拽本机关，安全取消并恢复原位 |
| 2 | 使当前脉冲失效 |
| 3 | 清除本机关的场上占用 |
| 4 | 移除本机关 |
| 5 | 库存数量恢复为原始总量 |
| 6 | 运行状态回到 SETUP，锁定的配置恢复可编辑 |
