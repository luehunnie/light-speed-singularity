> 版本：v0.2-单面四向

> 作者：潘陈俣
> 优先级：P0
> 适用光形态：光线 ✅ | 光粒 ⏳

## 1. 机关概述

单格斜面镜（单面四向）占据一个网格格。对角线方向有一面反射镀层，共四种朝向。从正面入射的光线/光粒反射；从背面入射的**按照墙体规则处理（停止传播）**。

与两面镜的核心区别：

| 特性 | 两面镜 | 单面四向 |
|---|---|---|
| 朝向数量 | 2 | 4 |
| 双面反射 | ✅ 两面均反射 | ❌ 仅正面反射 |
| 背面行为 | 也会反射 | **等同墙体** |
| 关卡空间 | 中 | 大——一个格子兼具镜面和墙体 |

## 2. 基本属性

| 属性 | 值 |
|---|---|
| 占用格数 | 1 格 |
| 朝向数量 | 4 种 |
| 默认朝向 | `L/`（左上镜） |
| 内部配置 | 朝向（右键循环切换） |
| 配置锁定时机 | 开始运行后锁定 |

### 四种朝向定义

代码标识直接表达正面方向——`L` 在前 = 正面在左，`R` 在后 = 正面在右。

```
L/ → L在/前 → 正面在/的左侧 → 左上镜
/R → R在/后 → 正面在/的右侧 → 右下镜
L\ → L在\前 → 正面在\的左侧 → 左下镜
\R → R在\后 → 正面在\的右侧 → 右上镜
```

| 代码 | 中文名 | 对角线 | 正面 | 背面 |
|---|---|---|---|---|
| `L/` | 左上镜 | `/`（左下→右上） | ↖ 左上方 | ↘ 右下方 |
| `/R` | 右下镜 | `/`（左下→右上） | ↘ 右下方 | ↖ 左上方 |
| `L\` | 左下镜 | `\`（左上→右下） | ↙ 左下方 | ↗ 右上方 |
| `\R` | 右上镜 | `\`（左上→右下） | ↗ 右上方 | ↙ 左下方 |

### L/R 命名约定

将对角线视为斜线，定义左右两侧：

```
/ 对角线（从↙看向↗）          \ 对角线（从↖看向↘）

左侧 ↖   右侧 ↘               左侧 ↙   右侧 ↗
```

- `L`（Left）= 线的**左侧**是正面（反射面）
- `R`（Right）= 线的**右侧**是正面（反射面）

### 核心原理：方向向量与进入方位

**方向向量表示光的去向，进入格子的方位是去向的反方向：**

```
→(1,0)  = 光向右走 = 从左侧进入      ←(-1,0) = 光向左走 = 从右侧进入
↓(0,1)  = 光向下走 = 从上侧进入      ↑(0,-1) = 光向上走 = 从下侧进入
```

对角线把格子分成两个三角区域。光从哪个区域进入格子，就命中对应的那一面。

### 朝向切换顺序

顺时针：`L/`(↖) → `\R`(↗) → `/R`(↘) → `L\`(↙) → `L/`

## 3. 交互规则

### 3.1 与光线交互

光进入镜面格后判定命中面：

```
命中正面 → 反射（使用对角线公式）
命中背面 → 停止传播（等同墙体）
```

**反射公式**（命中正面时使用）：

| 对角线 | 公式 |
|---|---|
| `/` | `(-y, -x)` |
| `\` | `(y, x)` |

### 3.5 与其他机关的交叉规则

> 基础规则：所有机关和场上物体不可重叠放置。

| 场景 | 规则 |
|---|---|
| 镜面 + 镜面（连续排列） | 连续判定，每格一步，最大传播步数保护 |
| `L/`（左上镜）+ 墙体 | 光从 `L/` 正面反射（↑或←方向）后射入墙体 → 按墙体规则 |
| `L/`（左上镜）背面 + 光线 | 光线从 ← 或 ↑ 方向命中 → **背面等同墙体，停止传播** |
| 镜面 + 分光器（未来） | 按正面/背面判定反射或阻挡 |
| 镜面 + 滤光片（未来） | 镜面不变色 |
| 镜面 + 光粒专属墙体（未来） | 按墙体规则 |
| 镜面 + 加速器/减速器（未来） | 速度变化由加速器/减速器决定，镜面不改变速度 |

## 4. 边界条件

| # | 条件 | 行为 |
|---|---|---|
| 1 | 入射 `(0,0)` | 停止 |
| 2 | 入射分量绝对值 >1 | 停止 |
| 3 | 传播中镜面被移除 | 停止，不崩溃 |
| 4 | 两镜面对射无限循环 | 最大传播步数保护 |
| 5 | 拖拽中光路经过原格 | 旧占用保留 |
| 6 | 光粒未实现 | 规则预定义，待验证 |
| 7 | 镜面在边界格 | 合法，可能下一格越界 |
| 8 | 镜面与水晶不可同格 | 占用表保证 |
| 9 | 沿对角线方向入射（如 `L/` 收到 ↗） | 阻挡 ⏳ 待定 |
| 10 | 背面 vs 墙体视觉 | 行为相同；背面不显墙体纹理 |

## 5. 配置锁定

| 项 | 说明 |
|---|---|
| 锁定内容 | 朝向（4 种不可切换） |
| 锁定时机 | READY_TO_FIRE 时锁定 ⏳；当前原型非 SETUP 自动锁定 |
| 解锁时机 | R 重置回到 SETUP |
| 锁定期间 | 可移动布局，不可切换朝向 |

---

## 6. 重置规则（R）

R 完整关卡重置对镜面的影响：

1. 取消拖拽并恢复原位置
2. 使异步回调失效
3. 注销占用表中的记录
4. 删除镜面节点
5. 库存恢复原始总量
6. 回到 SETUP，配置恢复可编辑

**R 后重新拿取的镜面默认为 `L/`（左上镜）朝向。**

## 11. 方案对比：单面四向 vs 两面镜

| 维度 | 两面镜 | 单面四向（本方案） |
|---|---|---|
| 朝向数量 | 2 | 4 |
| 光学行为 | 双面反射 | 正面反射 + 背面阻挡 |
| 玩家认知负担 | 低 | 中 |
| 关卡设计空间 | 中 | 大——一格兼具镜面和墙体 |
