## 1. 机关概述

光线形态水晶是关卡固定目标对象。

它的主条件固定为：

> **只有 RAY 光线满足本水晶的光形态条件。**

PARTICLE 光粒命中时不能点亮这颗水晶。

如果该水晶未来同时启用了其他附加条件，则必须同时满足那些条件；本文只讨论“必须是 RAY”这一条件。

合法点亮后保持到 R / 关卡完整重置。

| 属性 | 值 |

| 项目 | 结论 |

| 是否允许关卡设计者预置 | ✅ |
| 是否允许进入玩家机关栏 | ❌ |

| 最终理由 | 水晶定义“哪一种光必须到达哪里”，应由关卡设计决定位置 |

## 3. 交互规则

### 3.1 与光线交互

- 任意合法 RAY 到达本格：满足“光线形态”条件；
- 若没有其他附加条件：点亮；
- 若还有其他附加条件：继续检查其他条件；
- 水晶不改变 RAY 方向、颜色或传播状态。

### 3.2 与光粒交互

- 任意 PARTICLE 到达本格：**不满足光线形态条件**；
- 不点亮；
- 不改变 PARTICLE 方向和速度。

### 3.3 多条件兼容

本水晶可与其他目标条件组合。

规则只有一句：

> 光线形态条件成立，并且所有其他已启用条件也成立，才最终点亮。

其他条件的具体规则由各自文档定义，本文不展开。

---

## 4. 边界条件

| # | 情况 | 行为 |
|---|---|---|
| 1 | RAY 命中，仅有形态条件 | 点亮 |
| 2 | PARTICLE 命中 | 不点亮 |
| 3 | RAY 命中，但其他附加条件失败 | 不点亮 |
| 4 | 已点亮后再被 PARTICLE 命中 | 保持已点亮 |
| 5 | R 重置 | 恢复未点亮 |

---

## 5. 配置锁定规则

关卡制作阶段确定该水晶及其附加条件；游玩阶段玩家不可移动、回收或修改条件。

---

## 6. 重置规则（R）

R 后：

- 清除点亮状态；
- 保留水晶初始位置；
- 保留所有关卡预设条件；
- 回到未点亮状态。

---

## 7. 与其他系统的交互边界

| 系统 | 关系 |
|---|---|
| 光传播系统 | 提供到达时真实光形态 |
| ObjectiveController | 判断本水晶条件是否满足 |
| 其他目标条件 | 可以组合，但由各自规则负责 |
| 库存 | 不进入玩家库存 |
| 场上占用 | 固定单格目标对象 |
