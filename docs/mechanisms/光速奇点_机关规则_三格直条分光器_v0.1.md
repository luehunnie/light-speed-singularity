## 1. 机关概述

三格直条分光器是玩家可放置的多格光学机关，占据一条直线的 3 个网格格（横向一字或纵向一字，取决于朝向）。它把**一束入射光线**分成**两束平行、方向相同的出射光线**，是"一分为二"的光线分束机关。

分光器是**单向端口机关**：只在中间格的一个指定侧设有输入口，只在两端格的指定侧设有输出口。光线只能从输入口进入、从输出口射出；任何不遵循端口规则的光线（含斜向光线、从输出口反向射入、从非端口侧面射入）都视为碰撞墙体，停止传播。

分光器只支持光线（RAY）形态，不支持光粒（PARTICLE）；分光后各支路**继承入射光线的颜色属性**，不产生额外变色。当前分光器尚未实装，全部行为规则为目标规则 ⏳。

| 朝向 | 4 方向：上 / 下 / 左 / 右（以光线输入方向命名） |

| 可被玩家放置 | 是 |
| 可被玩家移动 | 是 |
| 可被回收 | 是 |
| 内部配置 | 朝向（上 / 下 / 左 / 右，右键顺时针切换） |
| 配置锁定时机 | 目标行为：开始运行后锁定 ⏳；当前原型：非 SETUP 状态锁定 |
| 是否改变光粒速度 | 不适用——光粒不支持 |
| 是否改变光线颜色 | 否——分光后各支路继承入射光颜色 |
| 旋转行为 | 有——右键顺时针旋转 90°，朝向与输入方向绑定，占用格位重算 |

### 2.1 玩家道具适用性

> 本节为强制项。不能只填写"可被玩家放置"，必须解释为什么适合或不适合进入玩家机关栏。

| 项目 | 结论 |
|---|---|
| 是否允许关卡设计者预置 | ✅ |
| 是否允许进入玩家机关栏 | ✅ |
| 是否允许玩家主动放入场景 | ✅ |
| 是否允许玩家移动/回收 | ✅ |
| 推荐定位 | 两者皆可（玩家道具 + 关卡预置） |
| 作为玩家道具的解谜价值 | 玩家可主动选择分光位置和朝向，把一束光分成两束平行光，实现"一次发射同时覆盖两个目标"的分束解谜，扩展光路拓扑的构造空间 |
| 作为玩家道具的风险 | 分光可让玩家绕过墙体、扩大光的覆盖范围、或让"单束光只到一个目标"的关卡约束被轻易破解，形成万能解 |
| 最终理由 | 分光是光线章节的核心机制之一，作为玩家道具能提供主动构造光路拓扑的决策空间；风险通过关卡配额（机关栏数量）与关卡布局约束控制 |

## 3. 交互规则

### 3.1 与光线交互 ⏳

分光器是单向端口机关，光线进入判定如下：

| 响应类型 | 触发条件 | 传播行为 |
|---|---|---|
| 分光 | 光线从输入口进入（方向与朝向对应的输入方向一致，且命中中间格的输入侧） | 一束入射光分为两束平行出射光，分别从两端格的输出口射出，出射方向与入射方向相同 |
| 停止 | 光线命中分光器的任何非输入位置（两端格、中间格非输入侧、输出口反向、侧面） | 传播立即停止，视为碰撞墙体 |
| 停止 | 斜向入射（8 方向中的 4 个对角方向） | 分光器不支持斜向光线，视为碰撞墙体，传播立即停止 |

> 分光器**不支持斜向光线**：8 个合法传播方向中的 4 个对角方向（↘ `(1,1)`、↙ `(-1,1)`、↗ `(1,-1)`、↖ `(-1,-1)`）命中分光器时，无论命中哪个格、哪一侧，一律视为碰撞墙体，传播立即停止，不进入分光判定。

**逐格传播顺序**（玩法设计 §6）：

```
1. 光进入下一格
2. 记录该格（坐标、入射方向、是否有水晶）——分光器中间格记录的是入射方向
3. 尝试激活该格水晶（分光器占用的格不与其他机关/水晶同格，故实际无水晶）
4. 查询机关 → 判定是否命中输入口 → 分光 / 停止
5. 若分光，两支出射光分别从两端格输出口沿原方向继续传播
```

> 关键点：分光后两支光束的方向都与入射方向相同（如"从下往上"仍是"从下往上"），只是在空间上平移到两端格。入射光在分光器内被完全消耗，**不存在**从中间格直穿而出的第三支光。

### 3.2 与光粒交互 ❌

光粒（PARTICLE）不支持分光。光粒命中分光器的任何格、任何侧，都视为碰撞墙体，停止传播。分光器不改变光粒速度，也不产生任何光粒分支。

| 入射条件 | 行为 |
|---|---|
| 任意方向光粒进入分光器任一占用格 | 被阻挡，停止 |

### 3.3 与发射器的关系

本机关不直接影响发射器。发射器发出的光线按 §3.1 规则与本机关交互；发射器发出的光粒按 §3.2 规则被阻挡。

### 3.4 玩家操作权限

| 操作 | SETUP | READY_TO_FIRE ⏳ | PULSE_ACTIVE | MOVE_WINDOW | COMPLETED |
|---|---|---|---|---|---|
| 从库存拿取 | ✅ | ✅ | ✅ | ✅ | ❌ |
| 首次放置 | ✅ | ✅ | ✅ | ✅ | ❌ |
| 跨格移动 | ✅ | ✅ | ✅（扣移动次数） | ✅（扣移动次数） | ❌ |
| 回收至库存 | ✅ | ✅ | ✅ | ✅ | ❌ |
| 切换内部配置（右键旋转朝向） | ✅ | ❌ | ❌ | ❌ | ❌ |
| 拖拽取消/回滚 | ✅ | ✅ | ✅ | ✅ | ❌ |

> 布局编辑（放置/移动/回收）在所有非 COMPLETED 状态下允许。
> 内部配置（朝向）仅在 SETUP 状态下可编辑。
> 运行期跨格移动消耗移动次数；首次放置、回收和取消不消耗。
> 多格移动时 3 格占用同时校验，任一格非法则移动失败并完整回滚。

### 3.5 与其他机关的交叉规则

> 基础规则：所有机关和场上物体不可重叠放置。

| 场景 | 规则 |
|---|---|
| 分光器 + 分光器（级联） | 前一个分光器的每支出射光独立入射后一个分光器，各自按端口规则判定（命中输入口则继续分光，否则停止） |
| 分光器 + 镜面（斜面镜/平面镜） | 分光后的每支光独立入射镜面，按镜面规则反射；镜面反射后的光入射分光器也按端口规则判定 |
| 分光器 + 墙体 | 分光后的出射光若下一格是墙体，按墙体规则停止 |
| 分光器 + 滤光片（未来） | 分光后的每支光独立经过滤光片，各自做薄膜面平行判定与颜色判定（滤光片文档已预留此交叉） |
| 分光器 + 水晶 | 分光后的每支光独立命中水晶，可分别点亮 |
| 分光器 + 光粒加速器/减速器 | 分光器只支持光线，光粒不会进入分光器；两者空间上不可重叠 |

## 4. 边界条件

| # | 边界条件 | 行为 |
|---|---|---|
| 1 | 入射方向为零向量 `(0, 0)` | 非法方向，传播停止 |
| 2 | 入射方向分量绝对值大于 1（如 `(2, 0)`） | 非法方向，传播停止 |
| 3 | 斜向入射（如 `(1, 1)`、`(1, -1)`） | 不支持，视为碰撞墙体，传播停止 |
| 4 | 从输出口反向射入（输出口不可输入） | 视为碰撞墙体，传播停止 |
| 5 | 从非端口侧面射入（两端格外侧、中间格非输入侧） | 视为碰撞墙体，传播停止 |
| 6 | 分光器在传播过程中被移除 | 传播停止，不崩溃 |
| 7 | 多个分光器级联分光 | 支路数量呈指数增长，由最大传播步数（128）与分支队列上限保护 |
| 8 | 分光器部分格在地图边界外 | 放置时校验 3 格均在地图合法区域内，任一格越界则拒绝 |
| 9 | 分光器与水晶/其他机关重叠 | 放置时校验 3 格均无占用冲突，任一冲突则拒绝（一格最多一个机关） |
| 10 | 分光后支路光的颜色 | 继承入射光颜色，不改变 |
| 11 | 光粒命中分光器 | 被阻挡，停止（光粒不支持） |
| 12 | 运行期拖拽分光器期间光路经过原占用格 | 拖拽期间 3 格旧占用均保留，原格仍视为有机关（预览不写入占用记录） |

## 5. 配置锁定规则

| 规则项 | 说明 |
|---|---|
| 锁定内容 | 分光器朝向（右键旋转不可用） |
| 锁定时机 | 目标行为：点击"开始运行"进入 READY_TO_FIRE 时锁定 ⏳；当前原型：非 SETUP 自动锁定 |
| 锁定后行为 | 右键旋转无响应，但可放置新分光器或移动已有分光器 |
| 解锁时机 | R 完整重置，回到 SETUP 状态 |
| 锁定期间可否移动 | ✅——锁定只关朝向旋转，布局编辑不受影响 |

## 6. 重置规则（R）

R 为完整关卡重置。对分光器的影响：

| 步骤 | 行为 |
|---|---|
| 1 | 若正在拖拽分光器，安全取消拖拽并恢复原位置 |
| 2 | 使当前脉冲失效 |
| 3 | 清除分光器 3 格的场上占用记录 |
| 4 | 移除分光器节点 |
| 5 | 库存数量恢复为关卡原始总量 |
| 6 | 运行状态回到 SETUP，锁定的朝向恢复可编辑 |

> R 后重新从库存拿取的分光器默认为右（RIGHT）朝向，不保留 R 之前的朝向（待成员确认默认朝向）。

## 7. 与其他系统的交互边界

> 核心原则：分光器只负责判定端口命中并把一束光分成两束，不越界修改其他系统的状态。

| 涉及系统 | 本机关与它的关系 |
|---|---|
| 光传播系统 | 光线命中输入口 → 产生 2 支同向平行分支并入传播分支队列；命中其他位置 → 停止 |
| 场上占用 | 放置/移动/回收时登记或注销 3 格占用；多格占用原子提交或回滚 |
| 库存 | 放置时消耗库存，回收时归还库存；新拿取默认右（RIGHT）朝向 |
| 运行状态 | 控制朝向旋转是否可编辑（SETUP 可旋转，其余锁定）；不影响布局移动 |
| 视觉表现 | 朝向切换对应外观变化；外观不反向决定分光方向 |

## 8. 机关专属规则详情

### 8.1 朝向定义与切换顺序

朝向以**光线输入方向**命名：朝向为"上"表示输入光线从下往上（方向 `(0,-1)`）进入输入口。右键切换按顺时针循环：

```
右(1,0) → 下(0,1) → 左(-1,0) → 上(0,-1) → 右(1,0)（循环）
```

| 朝向 | 输入方向（光线来向→去向） | 主体 3 格排列 |
|---|---|---|
| 上 | 从下往上 `(0,-1)` | 横向一字（1×3） |
| 下 | 从上往下 `(0,1)` | 横向一字（1×3） |
| 右 | 从左往右 `(1,0)` | 纵向一字（3×1） |
| 左 | 从右往左 `(-1,0)` | 纵向一字（3×1） |

> 图例：`■` = 分光器占用格　`↑↓←→` = 输入/输出方向　`IN` = 输入口　`OUT` = 输出口

### 8.2 朝向 = 上（输入方向 `(0,-1)`，从下往上）

主体 3 格横排：`(1,2)` `(2,2)` `(3,2)`，中间格 `(2,2)`。

```
        出射1↑          出射2↑
          │                │
   ┌──────┴───┐ ┌────────┐ ┌───┴──────┐
   │  (1,2)   │ │  (2,2) │ │  (3,2)   │
   │   OUT    │ │   IN   │ │   OUT    │
   └──────────┘ └───▲────┘ └──────────┘
                    │ 入射 ↑ (0,-1)
                  (2,3)
```

| 端口 | 所在格 | 位置 | 方向 |
|---|---|---|---|
| 输入口 | `(2,2)` | 下侧 | 接受 `(0,-1)` |
| 输出口 1 | `(1,2)` | 上侧 | 输出 `(0,-1)` |
| 输出口 2 | `(3,2)` | 上侧 | 输出 `(0,-1)` |

### 8.3 朝向 = 下（输入方向 `(0,1)`，从上往下）

主体 3 格横排：`(1,2)` `(2,2)` `(3,2)`，中间格 `(2,2)`。

| 端口 | 所在格 | 位置 | 方向 |
|---|---|---|---|
| 输入口 | `(2,2)` | 上侧 | 接受 `(0,1)` |
| 输出口 1 | `(1,2)` | 下侧 | 输出 `(0,1)` |
| 输出口 2 | `(3,2)` | 下侧 | 输出 `(0,1)` |

### 8.4 朝向 = 右（输入方向 `(1,0)`，从左往右）

主体 3 格竖排：`(2,1)` `(2,2)` `(2,3)`，中间格 `(2,2)`。

| 端口 | 所在格 | 位置 | 方向 |
|---|---|---|---|
| 输入口 | `(2,2)` | 左侧 | 接受 `(1,0)` |
| 输出口 1 | `(2,1)` | 右侧 | 输出 `(1,0)` |
| 输出口 2 | `(2,3)` | 右侧 | 输出 `(1,0)` |

### 8.5 朝向 = 左（输入方向 `(-1,0)`，从右往左）

主体 3 格竖排：`(2,1)` `(2,2)` `(2,3)`，中间格 `(2,2)`。

| 端口 | 所在格 | 位置 | 方向 |
|---|---|---|---|
| 输入口 | `(2,2)` | 右侧 | 接受 `(-1,0)` |
| 输出口 1 | `(2,1)` | 左侧 | 输出 `(-1,0)` |
| 输出口 2 | `(2,3)` | 左侧 | 输出 `(-1,0)` |

### 8.6 分光拓扑总结

- **输入**：单束光线，方向 = 朝向对应的输入方向。
- **输出**：两束光线，方向均与输入方向相同，空间上平移到两端格。
- **拓扑**：单输入 → 双分支（平行同向），不改向、不变色、不变速。
- **端口语义**：输入口只进不出；输出口只出不进；其余所有命中（含斜向光线）一律视为碰撞墙体。
