## 1. 机关概述

主发射器是每关的固定核心发射对象。它由关卡设计者预置位置和初始配置，玩家不能移动或回收主发射器。

在 `SETUP` 阶段，玩家可以调整主发射器的八方向朝向；若本关允许形态切换，还可以在 RAY / PARTICLE 之间切换初始光形态。

点击“开始运行”后，主发射器的当前方向和当前初始光形态锁定。之后玩家通过 `Space` 发射；`R` 执行完整关卡重置并恢复初始配置。

PARTICLE 从主发射器发射时，默认以**标准速度**开始传播。

### 2.1 玩家道具适用性

| 项目 | 结论 |
|---|---|
| 是否允许关卡设计者预置 | ✅ |
| 是否允许进入玩家机关栏 | ❌ |

| 推荐定位 | 仅关卡预置 |

## 3. 交互规则

### 3.1 发射 RAY

当当前光形态为 `RAY` 时：

1. 玩家按 `Space`；
2. 读取当前主发射器格；
3. 读取当前八方向朝向；
4. 生成一次 RAY 发射请求；
5. RAY 按光线传播规则同步计算完整路径；
6. 主发射器本身不直接处理镜面、水晶、墙体等后续交互。

### 3.2 发射 PARTICLE

当当前光形态为 `PARTICLE` 时：

1. 玩家按 `Space`；
2. 读取当前主发射器格；
3. 读取当前八方向朝向；
4. 创建一个 PARTICLE；
5. 初始速度固定为**标准**；
6. PARTICLE 按整数 Tick 和八方向光粒规则逐格传播；
7. 后续速度变化由加速器、减速器、光屏障等机关处理。

### 3.3 与发射器自身配置的关系

玩家只能在 `SETUP` 中修改主发射器方向和初始光形态。

- 方向：八方向均可直接调整；
- 光形态：仅当关卡允许切换时可在 RAY / PARTICLE 间切换；
- 若关卡固定光形态，则 `Q` 不改变形态；
- 点击开始运行后，方向与初始光形态锁定；
- 运行过程中若存在光形式转换器，只改变传播中的光，不反向修改主发射器初始配置。

### 3.4 玩家操作权限

| 操作 | SETUP | READY_TO_FIRE ⏳ | PULSE_ACTIVE | MOVE_WINDOW | COMPLETED |
|---|---|---|---|---|---|
| 调整八方向朝向 | ✅ | ❌ | ❌ | ❌ | ❌ |
| 切换 RAY / PARTICLE | ✅（仅关卡允许时） | ❌ | ❌ | ❌ | ❌ |
| 发射 | ❌ | ✅ | ❌ | ✅ | ❌ |
| 移动发射器 | ❌ | ❌ | ❌ | ❌ | ❌ |
| 回收发射器 | ❌ | ❌ | ❌ | ❌ | ❌ |
| 完整重置 R | ✅ | ✅ | ✅ | ✅ | ✅ |

> 当前真实代码仍只有 SETUP / PULSE_ACTIVE / MOVE_WINDOW / COMPLETED 四状态；READY_TO_FIRE 与开始运行门属于目标玩法状态。

### 3.5 与其他机关的交叉规则

| 场景 | 规则 |
|---|---|
| 主发射器 + 镜面 | 镜面只处理发射后的传播路径 |
| 主发射器 + 加速器/减速器 | PARTICLE 先以标准速度发射，到达机关后才改变速度 |
| 主发射器 + 光屏障 | 按发射形态、方向和速度规则处理 |
| 主发射器 + 水晶 | 水晶由传播结果决定是否点亮 |
| 主发射器 + 光形式转换器（后续） | 转换器只改变传播中的光形态，不修改主发射器初始形态 |

## 4. 八方向规则

主发射器的 RAY 与 PARTICLE 均采用同一套八方向：

| 方向 | 向量 |
|---|---|
| RIGHT | `(1,0)` |
| DOWN_RIGHT | `(1,1)` |
| DOWN | `(0,1)` |
| DOWN_LEFT | `(-1,1)` |
| LEFT | `(-1,0)` |
| UP_LEFT | `(-1,-1)` |
| UP | `(0,-1)` |
| UP_RIGHT | `(1,-1)` |

玩家不是通过“每次旋转 45°”选择方向，而是直接输入目标方向。

## 5. 默认按键

| 功能 | 默认按键 |
|---|---|
| 上 | `W` / `↑` |
| 下 | `S` / `↓` |
| 左 | `A` / `←` |
| 右 | `D` / `→` |
| 右上 | `W+D` / `↑+→` |
| 右下 | `S+D` / `↓+→` |
| 左下 | `S+A` / `↓+←` |
| 左上 | `W+A` / `↑+←` |
| 切换 RAY / PARTICLE | `Q` |
| 发射 | `Space` |
| 完整重置 | `R` |

规则：

- 斜向通过两个正交方向键同时输入；
- 相反方向同时输入不产生有效方向；
- `Q` 只在关卡允许切换且处于 SETUP 时有效；
- `Space` 是否生效由运行状态决定；
- `R` 始终是完整关卡重置，不承担旋转或局部重置功能。

## 6. 配置锁定规则

| 配置项 | SETUP | 开始运行后 |
|---|---:|---:|
| 主发射器方向 | 可修改 | 锁定 |
| 主发射器初始光形态 | 关卡允许时可修改 | 锁定 |
| 主发射器位置 | 玩家始终不可修改 | 玩家始终不可修改 |
| PARTICLE 初始速度 | 固定标准 | 固定标准 |

开始运行后的锁定只针对“人工初始配置”，不阻止传播过程中其他机关改变光的方向、速度或形态。

---

## 7. 重置规则（R）

R 为完整关卡重置。

对主发射器：

1. 使当前光执行失效；
2. 清理当前 RAY / PARTICLE；
3. 主发射器恢复关卡设计者配置的初始方向；
4. 主发射器恢复关卡设计者配置的初始光形态；
5. 若本关允许形态切换，回到 SETUP 后玩家可再次修改；
6. 重新要求点击“开始运行”；
7. 返回 SETUP。

## 8. 与其他系统的交互边界

| 涉及系统 | 本机关与它的关系 |
|---|---|
| 光传播系统 | 提交统一发射请求，不直接执行路径算法 |
| RAY 系统 | 提供起点、方向、形态 |
| PARTICLE 系统 | 提供起点、方向、标准初始速度 |
| 运行状态 | 控制何时允许配置与发射 |
| 关卡配置 | 决定初始位置、初始方向、初始形态、是否允许形态切换 |
| 库存 | 不进入玩家库存 |
| 场上占用 | 固定占用一个格 |
| 视觉表现 | 方向和形态由逻辑状态驱动视觉，不允许视觉反向决定逻辑 |

## 9. 主发射器专属规则详情

### 9.1 关卡配置

关卡设计者至少可配置：

- 发射器初始位置；
- 初始朝向；
- 初始光形态；
- 是否允许玩家切换 RAY / PARTICLE。

P0 默认只有一个主发射器。次级发射器属于后续附加机关，不与主发射器混为同一规则。

### 9.2 光形态切换

若：

```text
allow_form_switch = false
```

则玩家无法使用 `Q` 改变初始形态。

若：

```text
allow_form_switch = true
```

则玩家可在 SETUP 中：

```text
RAY ↔ PARTICLE
```

点击开始运行后锁定。

### 9.3 PARTICLE 初始速度

主发射器每次产生 PARTICLE 时：

```text
speed_tier = STANDARD
```

不继承上一颗光粒的速度，也不因上一轮加速/减速结果改变。

## 10. 边界条件

| # | 边界条件 | 行为 |
|---|---|---|
| 1 | SETUP 中按方向键 | 更新主发射器朝向 |
| 2 | READY_TO_FIRE 后按方向键 | 不修改方向 |
| 3 | 关卡禁止形态切换时按 Q | 无效 |
| 4 | 关卡允许切换且 SETUP 按 Q | RAY / PARTICLE 切换 |
| 5 | 开始运行后按 Q | 无效 |
| 6 | PARTICLE 发射 | 初始速度始终为标准 |
| 7 | 多次发射 PARTICLE | 每颗均独立以标准速度创建 |
| 8 | COMPLETED 后按 Space | 无效 |
| 9 | 任意状态按 R | 完整关卡重置 |
| 10 | 两个相反方向键同时输入 | 不产生新的有效朝向 |
| 11 | 发射器格与其他固定对象重叠 | 非法关卡配置 |
