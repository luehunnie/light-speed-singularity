# 1. 项目定位

《光速奇点》是一款以固定网格光学解谜为主要产品价值、以中国科学家宣传与科学知识传播为内容目标的单机游戏。

玩家通过机关栏布置机关，确认“开始运行”后使用光线或光粒完成水晶和其他目标。项目首先保证解谜规则稳定、反馈清楚、关卡可重复验证，再通过成就弹窗和科学家档案传递科学家成果与科研精神。

项目面向小团队首次完整开发，不追求商业化规模。

---

# 2. 目标用户

主要包括：

- 喜欢轻量解谜的普通玩家；
- 中学生和大学生；
- 对中国科学家、科学史和光学感兴趣的人；
- 学校项目评审、展示和体验人员。

9月5日前以能够快速理解玩法和内容的校内展示用户为主要验收对象。

# 4. 9月5日前最小业务范围

## 4.1 游戏

- 可启动；
- 主界面；
- 选关；
- 三章节代表关卡；
- 光线；
- 光粒；
- 基础机关；
- 开始运行按钮；
- 重置；
- 通关；
- 最小存档；
- Windows包。

关卡数量采用弹性策略：

- 不改变三章节；
- 每章至少有代表性正式内容；
- 内部目标每章约2关；
- 进度不足时缩小单关规模和附加机关。

## 4.2 科学家宣传

采用方案A：

- 至少1位重点科学家；
- 至少3项正式成就；
- 右下角成就弹窗；
- 主界面成就展示入口；
- 科学家档案；
- 可靠资料来源。

科学家重点对象可围绕戴琼海院士展开。文档不在缺少来源时编写具体人物事实和引语。

## 4.3 交付

# 5. 科学家内容方式

## 成就弹窗

包含：

- 图标；
- 成就名；
- 科学家姓名；
- 简短科研精神说明；
- 档案解锁提示。

要求：

- 右下角出现；
- 不暂停游戏；
- 不遮挡核心操作；
- 多个成就排队；
- 之后可回看。

## 成就展示页

显示：

- 已解锁和未解锁；
- 图标和名称；
- 科学家；
- 成果或精神简介；
- 获取条件；
- 资料来源或扩展阅读。

## 档案

可包含：

- 基本信息；
- 研究领域；
- 代表成果；
- 重要经历；
- 科研精神；
- 可靠来源。

弹窗负责提醒，档案负责完整内容。

---

# 6. 内容真实性

必须：

- 使用可靠来源；
- 不编造经历；
- 不夸大个人贡献；
- 不把团队成果错误归于个人；
- 区分历史事实、科普解释和游戏表达；
- 对争议信息说明；
- 保存来源名称和链接记录；
- 不使用无法确认出处的名言。

科学知识可以简化，但不能为了玩法制造错误。

# 10. 业务验收

- 游戏可完整运行；
- 玩家理解开始运行、光线、光粒、移动和重置；
- 三章节均有代表性内容；
- 科学家内容真实且注明来源；
- 成就不打断核心玩法；
- 成就展示入口清楚；
- 至少1位重点科学家和3项成就；
- 关卡和UI不要求玩家修改代码；
- Windows包独立运行；
- 来源、授权和已知问题齐全。
