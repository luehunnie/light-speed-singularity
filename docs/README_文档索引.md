## 6. 优先级说明

发生冲突时使用以下顺序：

1. 用户在当前任务中的明确决定；
2. 当前仓库真实 Git、代码、场景、资源和实际运行结果；
3. 当前阶段交接说明或阶段总文档；
4. 当前正式核心文档；
5. API 契约；
6. 操作指南；
7. `docs/ai/` 当前协作文档；
8. `docs/ai/archive/` 历史归档。

补充：

- 目标设计不能覆盖真实实施状态；
- archive 不能覆盖当前文档；
- 无法确认时必须记录为待确认。
