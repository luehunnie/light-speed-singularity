## 4. 本地 AI 协作目录

`docs/ai/` 用于本地 AI 协作上下文、当前状态、下一步任务计划和测试清单：

- 该目录被 `.gitignore` 忽略；
- 不属于正式仓库文档；
- 不替代 `docs/` 根目录、`docs/api/` 和 `docs/guides/` 中的正式文档；
- 其中 `archive/` 只保存历史资料，不得用来覆盖当前规则。

---

## 5. 优先级说明

发生冲突时按以下顺序处理：

1. 当前任务提示词中的明确边界；
2. 最新正式核心文档；
3. API 契约；
4. 操作指南；
5. 当前真实代码与运行结果；
6. `docs/ai/` 当前协作文档；
7. `docs/ai/archive/` 历史归档。

无法确认的内容应记录为“需要团队确认”，不得由 AI 静默决定。
